# Explain Code

When the user asks you to explain code:

1. Read the file or snippet indicated
2. Break the explanation into:
   - **What it does** (overview)
   - **How it does it** (step by step)
   - **Why it does it** (design decisions)
3. Use analogies when appropriate
4. Highlight common pitfalls or edge cases
5. If there are better alternatives, mention them
